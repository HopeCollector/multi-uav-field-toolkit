# Synthetic examples

Everything in this directory is fabricated for documentation and tests. It must not be
replaced with real field telemetry or reconstructed experimental trajectories.

`status.json` mirrors one packet emitted by the mock sender. Values and identifiers are
generic and do not describe a vehicle or deployment.

`tuning/` contains invented parameter names, bounds, scenario factors, constraints, and
objective ranges for the bundled deterministic evaluator. Its recommendations are not
field measurements, real vehicle settings, or evidence of physical safety.
